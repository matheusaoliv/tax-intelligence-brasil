# Skills e ferramentas de design

Pesquisa em 17/11/2026. Estrelas são dinâmicas e não garantem qualidade. Revisar licença, escopo, dependências e permissões antes de instalar.

## UI UX Pro Max
https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
Design system, estilos, paletas, tipografia, padrões UX e dashboards.
~~~bash
npm install -g ui-ux-pro-max-cli
uipro init --ai codex
~~~

## Impeccable
https://github.com/pbakaus/impeccable
Crítica, auditoria e refinamento visual.
~~~bash
npx impeccable install
~~~
No Codex, conferir/aprovar hook conforme documentação.

## shadcn/ui
https://github.com/shadcn-ui/ui
Biblioteca de componentes React acessíveis, não uma skill. Docs: https://ui.shadcn.com/docs

## Taste Skill
https://github.com/Leonxlnx/taste-skill
Direção de arte para landing page/site comercial.
~~~bash
npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"
~~~
Opcional para o site público.

## Frontend Design
https://github.com/PracticalSwan/agent-skills
Skill frontend-design/SKILL.md para responsividade, acessibilidade, estados e validação visual.

## Composição
UI UX Pro Max define o sistema visual; shadcn/ui fornece componentes; Impeccable revisa; Taste Skill fica reservada ao marketing site; Frontend Design é checklist. Não carregar tudo em toda tarefa.
